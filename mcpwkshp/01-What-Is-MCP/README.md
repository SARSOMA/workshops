# §1 — Introduction to MCP

**Goal**: by the end of this 15-minute section, even someone who has **never heard of MCP before** can:

- recite what MCP stands for and who introduced it,
- explain in one sentence what problem it solves,
- name the **three primitives** an MCP server can expose,
- point at real MCP servers people use today, and
- explain *why* connecting an MCP server has a real, ongoing cost in the model's **context window**.

No prerequisites. If you've used Copilot, Claude, or ChatGPT once, that's enough background.
